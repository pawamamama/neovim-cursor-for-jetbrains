## v0.9.32 —— 多光标支持 + 一整轮 bug 修复

> 自 v0.9.14 以来第一次功能发布。

---

## 新增：多光标

| 场景 | 支持 |
|---|---|
| 普通多光标（`Alt+点击`、`Ctrl+Alt+↑/↓`） | ✅ |
| 块选区（`Alt+鼠标拖拽` 列选） | ✅ |
| 每个光标独立拖尾 | ✅ |
| 相邻行分组（避免辉光串扰） | ✅ |

### 与上游 v0.5.1 的四处差异

| 差异 | 上游 | 本版 | 为什么 |
|---|---|---|---|
| 死光标回收 | `size` 比较 | **帧号标记-清除** | 官方文档：cursor 合并时一增一减、数量不变，size 比较清不掉 |
| 新光标起飞源 | 遍历顺序前一个 | **像素距离最近** | `Alt+散点选`时上游会从远处飞入 |
| 短跳判据 | 像素反推字符数 | **原生字符偏移** | 中文/emoji/换字号时像素法误判 |
| 辉光强度 | 全局字段 | **逐光标独立** | 否则静止光标也发光 |

## 新增：诊断日志

**设置面板勾选即可**（`Settings → Tools → Neovide Cursor`），改 JVM 参数、不用重启都不用。

覆盖 7 条不变量，每条日志直接写 `OK` / `BAD`：

| # | 不变量 | 违反说明 |
|---|---|---|
| I1 | 目标变化时角点必须动 | 拖尾冻结 |
| I2 | 静止时角点应收敛 | 永不收敛 |
| I3 | 偏移 ≤ 200px | 拖尾失控 |
| I4 | 块选区各行 x 一致 | 斜度不一致 |
| I5 | 拖尾数 = caret 数 | 某些光标没画 |
| I6 | 块选区方向匹配数组 | 选错数组 |
| I7 | 普通光标跟 vp | 跟随点错误 |

## 修复的 bug

| 问题 | 根因 |
|---|---|
| 两个光标（宽度不一致） | `getLineCursorWidth()` 是倍率不是像素 |
| 块选区中文失效 | key 用 offset，输入中文后每行都变 |
| 辉光串扰/撕裂 | `maxOffset` 取全局最大 |
| 块选区拖尾长度不一致 | 错误用了 `startFrom` |
| 块选区加速度不均 | 每行独立算 `charsMoved`，走了不同分支 |
| 选区扩展拖尾不跟 | **跟错了 API**（`lead` 是锚点，`vp` 才是活动端） |
| 块选区向右扩失效 | 两个数组各管一个方向，用错了 |
