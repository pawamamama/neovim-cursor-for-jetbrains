## 六、已确认不需要做的事

- **U-M-3（静止后仍每帧重绘）保持现状，不修**（2026-10-31 用户拍板）。
  用户原话：「这个属于硬性规定先保证观感后续有更好方案再优化」。
  现状：`tickSpring` 每帧无条件 `computeTrailBounds + submitRepaint`，审计估算
  0.3%~3% 单核持续占用（按脏区面积折算，**估算非采样**），不构成掉帧。
  加「静止跳过」门的前提是先把「静止帧不出残影」变成可断言的事实 —— 在那之前不改。
  代码处已加同义注释（`CaretAnimator.tickSpring` 末尾）。
- 不修平台 252 光标冻结（BUG-008 已修复并经用户实机验证，见 docs/BUG-LOG.md）
- **VRegr2 的 R-5 / R-6 暂时不修**：它不是过期断言，是**真功能缺口**
  （`typingSmoothness` 既不参与 `matchAnimPreset` 比较，也不在改内置预设时派生副本）。
  修它要先回答「这个字段该不该跟动画预设」——那是产品决策，等用户定。
  门禁脚本已把它排除在失败门外，不会挡住任何工作。
- 不放宽任何 VRegr2 断言
- 不补历史 git tag（见 P7）
- 不对「彩虹（动态）」预设加配置迁移代码 —— 按纪律四-K，只有你一个用户，升级后重新点一次预设即可
- 不在面板重构之前动 §七 里列的任何一项
