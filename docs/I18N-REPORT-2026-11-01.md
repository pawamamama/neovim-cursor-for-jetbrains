## 三、研究记录（先查证，不凭记忆）

`plugins.jetbrains.com` 被本机网络策略拦截，改用本机 `idea-libs` 字节码
+ 一次性原型（已删除）实测：

| 实测 | 结果 |
|---|---|
| `DynamicBundle` + 无语言包 headless | **永远英文**，`-Duser.language=zh_CN` 无效 |
| `DynamicBundle.getResourceBundle(cl, path, Locale.ENGLISH)` | **无视传入 locale** |
| 纯 `ResourceBundle` 默认 `Control` | 中文系统上请求 ENGLISH **会取到 `_zh_CN`** |
| 纯 `ResourceBundle` + `getNoFallbackControl(FORMAT_PROPERTIES)` | en→root、zh_CN→`_zh_CN` ✅ |

**最终设计**：

```
资源包：java.util.ResourceBundle + getNoFallbackControl(FORMAT_PROPERTIES)
locale：LocalizationStateService（重启窗口读 lastSelectedLocale）
        → 取不到则 Locale.getDefault()
格式化：AbstractBundle.messageOrDefault(bundle, key, key, params)
兜底  ：整包缺失 / 平台类不可用 → 返回 key + 一次 warn，绝不让设置页 <clinit> 炸掉
```

所有 `zh*`（含 zh-TW / zh-Hant）一律落 `zh_CN`；只给 `zh` 时补国家码，
否则 no-fallback 链找不到 `_zh` 会落到英文。

## 八、已知缺口（不假装完成）

1. `plugin.xml` 菜单标题仍为中文（`Neovide 光标：动画预设` 等）。
2. Tools 菜单里的内置预设名仍为中文，可能与设置面板下拉显示两个名字。
3. `CustomPresets.nameError` 的中文校验原因会出现在英文对话框里。
4. 新建副本的 `" 副本"` 后缀属于用户数据命名，未翻译。
5. `CUSTOM_COLOR_LABEL` 现已无引用；`SliderSpec.unitSuffix` 是既有死字段。
   两者都在 `settings/` 层，按「本轮不动 settings」未删。
6. `com.intellij.AbstractBundle` / `com.intellij.l10n.LocalizationStateService`
   在 252 平台 jar 里标注 `@ApiStatus.Internal`；本机没有 2024.2
   （since-build=242）构件，**无法核实 242 上是否存在**。建议后续把
   Plugin Verifier 的 2024.2 校验接进交付门禁。
7. 英文值里三处 `'`（`preset's` ×2、`glow's`）当前都无参数调用，
   MessageFormat 不介入；将来加 `{0}` 时必须写成 `''`。
