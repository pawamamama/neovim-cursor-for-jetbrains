五、绘制层事实（决定「突兀感」的物理原因）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  5.1 辉光是 8 层同心外扩，层数不是亮度轴
      CaretTrailPanel.drawQuadGlow():
        float peak = config.glowOpacity * (glowColor.getAlpha()/255f) * quadGlow * glowFade;  // :1000-1001
        double layerAlpha = 1.0 - Math.pow(1.0 - peak, 1.0 / layers);                         // :1009
      每层半径 radius = glowWidth * i / layers，从外向内画；
      N 次根反解保证 N 层叠加后的累计不透明度 = peak。
      层数只决定离散粒度/平滑度，不改变整体亮度（NeovideConfig.java:40-59 有定义）。
      按层数减只有 n=0..8 共 9 档（0.550/0.503/0.451/0.393/0.329/0.259/0.181/0.095/0），
      最后一下仍是硬切 —— 不要按层数做淡出。

  5.2 线性 alpha 在感知上「前慢后快」
      默认 peak=0.55、8 层，最外层单层 alpha ≈ 24/255（9.5%）：
        进度 1.00 / 0ms    peak 0.550  外缘 24/255  内圈 0.490
        进度 0.50 / 37.5ms peak 0.275  外缘 10/255  内圈 0.238
        进度 0.25 / 56.3ms peak 0.138  外缘  5/255  内圈 0.118
        进度 0.00 / 75ms   peak 0      外缘  0
      外圈 4~5px 在前 40~55ms 就低于可见阈值，最后约 20ms 只剩 1px 内核；
      8ms/帧只有 9 帧，EDT 抖动时只剩 4~6 帧 → 主观「停一下，然后突然没了」。

  5.3 光晕面积会缩 15%~41%
      glowWidth = shadowBlurFactor × max(光标宽, 高)，按光标名义尺寸算，不随拉伸变化。
      跨行 32px → 收拢：可见环约 1009 → 599 px²（−41%）；
      同行 8px → 收拢：约 701 → 599 px²（−15%）。
      0.9.120 的淡出作用在大光晕上；0.9.125 推迟到最小光晕上 → 后者更突兀。

  5.4 重绘不是问题
      computeTrailBounds + submitRepaint 合并上一帧脏区，面板 setOpaque(false)，旧光晕会被擦掉。
      唯一边缘：shadowBlurFactor=0.6 时 glowPadding 可能不足以覆盖 √2×glowWidth；默认 0.2 安全。
