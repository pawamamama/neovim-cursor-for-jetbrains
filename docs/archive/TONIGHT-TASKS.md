## 任务清单

### T1 光标宽度可调（0 到 5px）

**改动：**
1. `NeovideCursorSettings.State` 加 `cursorWidthPx`（int，默认取 IDEA 值，clamp 0–5）
2. `SettingsField.FIELDS` 加表项（**纪律四-B：三层都要改**）
3. `copyFrom` 补一行
4. 面板 UI：总开关区加滑块
5. `CaretAnimator` 读取并用于绘制
6. 探针 `VCursorSize`

**验收：**
- 滑块 0–5，默认 = IDEA 原值
- **静止帧实测宽度 = 设置值**（关键，不能只在运动帧生效）
- 0px = 不画（等同于隐藏）
- 5px 时辉光半径按 5px 重算

---

### T2 光标长度可调（相对行高 0.3~1.0）

**改动：** 同 T1，字段 `cursorHeightRatio`（float，默认 1.0 = 顶格）

**验收：**
- 1.0 = 当前行为（顶格）
- 0.3 = 只占行高 30%（居中）
- **静止帧实测高度 = 行高 × 比例**

---

### T3 RGB 最小案例（实验性）

**范围：**
- 只改 `CaretTrailPanel:454-455` 一处
- `GradientPaint` 纵向渐变：拖尾末端 → 前缘
- **硬编码两色**（如 `#FFC0CB` → `#7B68EE`）
- 加一个隐藏开关（`-Dneovide.cursor.rgb=true`），默认关

**验收：**
- 开关开启时，5px 宽光标能看到上下颜色不同
- 开关关闭时，行为与现在完全一致
- parity 不受影响（默认关）
