## T1 / T2 光标尺寸

**位置**：`Settings → Tools → Neovide Cursor → 总开关`

```
光标宽度（0 = 跟随 IDEA）  [0 ----|---- 5]  0/1/2/3/4/5
光标高度（% 行高）          [30 --|------ 100]  30%~100%
```

**默认值**：宽度 0（跟随 IDEA）、高度 100%（顶格 = 原行为）。

**关键实现**：
- 尺寸通过 `trail.setTarget(cx, cy, w, h)` 每帧传入
- **静止时 setTarget 仍被调用**，所以静止也保持设置的大小（用户明确要求）
- 辉光自动跟着矩形走（`updateGlowRadius()` 已按 `max(w,h)` 算，未改）
- 宽度硬上限 5px（`Math.min(5.0, cursorWidthPx)`）

**不进预设**（设备级，用户明确要求）。

## T3 RGB 最小案例

**开启方式**：
```
Help → Edit Custom VM Options
加一行：-Dneovide.cursor.rgb=true
```

**效果**：拖尾纵向渐变（上端原色 → 下端 `#7B68EE`）。

**默认关闭**，理由是 parity 逐字节比对 —— 实验功能不能影响默认路径。

**实测**：parity 三件套全 OK（PhysicsParity / GeometryParity / TrailParityTest）。

**明天要做的可调版**：起止色、方向、是否跟随拖尾年龄。
