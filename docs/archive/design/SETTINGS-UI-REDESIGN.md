# SETTINGS-UI-REDESIGN —— 设置界面重做方案（0.9.5）

> 生成：2026-10-20　｜　基线 HEAD `3c3944d`，已安装 `0.9.4-settings`
> 本文是**给用户审批的方案**，不是实现契约。审批通过后再开团队落成契约。

---

## 0. 一句话

**0.9.4 的设置界面能用，但有 4 个已实测缺陷，且 16 项平铺不直观。**
本轮要做的：修 4 个 bug + 重排布局 + 加预设 + 滑块改吸附式 + 放开两个动画参数。

---

## 1. 已实测确认的 4 个缺陷（必修）

详见 `START-HERE.md` §6.5，这里只列结论：

| # | 缺陷 | 严重度 | 根因 |
|---|---|---|---|
| 1 | 8 个滑块数值标签拖动时全不更新 | **高** | `SliderKt.bindValue` 不注册 `ChangeListener` |
| 2 | 刻度数字挤成一团 | 中 | DSL `slider()` 默认 `paintLabels=true`，51~201 个标签 |
| 3 | 面板打开期间点 Tools，操作被覆盖 | **高** | `apply()` 无条件用旧 `pending` 覆盖 state |
| 4 | 切主题后原生光标复活，双套绘制 | **高** | 无 `EditorColorsListener` + `:606` 早退 |

## 2. 参数范围变更（已口头同意）

| 参数 | 0.9.4 契约 | 本轮 | 理由 |
|---|---|---|---|
| `animationLength` | 不做 | **0.05–0.35，步长 0.01** | “缎带感”必须要它：现在跨行 100ms 太快，Neovide 官方 150ms |
| `shortAnimationLength` | 不做 | **0.02–0.25，步长 0.01** | Neovide 官方 0.04，现在 0.11，要能调回去 |
| `trailFactors` | 只给“拉伸强度”滑块 | **保持** | 防用户调出扭曲四边形 |

**硬约束**：`animationLength` UI 上限 0.35（再大就撞 `RECOVERY_GAP_SECONDS=0.1` 的恢复判据）。

## 5. 滑块改吸附式

**形态**：滑块 + 输入框同行，滑块吸附固定刻度，输入框接受任意值，**右侧数值实时跟随**。

| 参数 | 滑块刻度 | 输入框范围 |
|---|---|---|
| 拖尾不透明度 | 0 / 25 / 50 / 75 / 100 | 任意 0–100 |
| 辉光峰值不透明度 | 0 / 25 / 50 / 75 / 100 | 同上 |
| 辉光层数 | 1–12 整数 | 整数 |
| 辉光外扩幅度 | 5 / 10 / 15 … 60 | 任意 5–60 |
| 拖尾密度 | 0 / 25 / 50 / 75 / 100 | 任意 |
| 拉伸强度 | 10 / 15 / 20 … 80（1.0–8.0 步长 0.5） | 任意 1.0–8.0 |
| 淡出前保持 | 0 / 50 / 100 … 500 ms | 任意 0–500 |
| 淡出时长 | 0 / 50 / 100 … 1000 ms | 任意 0–1000 |
| **跨行动画时长** | 5 / 10 / … / 35（0.05–0.35） | 任意 0.05–0.35 |
| **短动画时长** | 2 / 4 / 6 … 25（0.02–0.25） | 任意 0.02–0.25 |

**“标签实时跟随”是缺陷 1 的修复目标，8 个滑块必须 8/8 跟随。**

## 6. 跟随策略：**不做三选一，保持两个独立开关**

**这里推翻我上一版的建议。** 我上一版想做“三选一策略”并建议禁止某组合，经用户实测反驳后确认是错的：

| 组合 | 绘制套数 | 空闲 | 移动时 | 评价 |
|---|---|---|---|---|
| 隐藏原生 ✅ + 常驻刷新 ✅ | 1 | 8ms | 8ms | 默认，响应最快 |
| **隐藏原生 ✅ + 常驻刷新 ❌** | **1** | 120ms | **8ms（事件立即唤醒）** | **用户实测可用，单套绘制最省电** |
| 隐藏原生 ❌ + 常驻刷新 ❌ | **2** | 120ms | 8ms | 最差，双套绘制 |
| 隐藏原生 ❌ + 常驻刷新 ✅ | **2** | 8ms | 8ms | 双套但流畅（用户实测“卡一点”） |

**原因**：`caretPositionChanged` 每次都调 `wakeUp()`，**立刻拉回 8ms 档**；只有完全静止才降到 120ms，而静止时不需要响应。

**结论：保持两个独立复选框，不加策略选择器。** 只在双套绘制组合上给一句提示。

## 8. 明确不做

| 项 | 原因 |
|---|---|
| 多光标（Alt 列选） | 已确认不支持；需重构成 `Map<Editor, List<Animator>>`，独立大功能 |
| 残影模式输入不平滑 | 用户说“计入 md 先不做” |
| 流光 RGB 特效 | 用户说“后面做”；需改绘制 + 实测 p95 |
| 辉光双色渐变 | 同上，第二期 |
| `ACTIVE_DELAY_MS` 可配 | 用户实测 12ms 会“傻快”，内部常量永不暴露 |
| Jewel / Compose UI | `@Composable` 需 Compose 编译器插件，本项目纯 javac 离线构建，**Java 调不了**（javap 已确认） |

## 9. 布局重排（按 JetBrains 官方 Layout 规范）

来源：`plugins.jetbrains.com/docs/intellij/layout.html`

关键规则（原文）：
- 标签长度相近的输入控件放不同行，输入框左对齐
- **左边距永远左对齐标签**（跨平台一致）
- 2–3 个短标签复选框可同放一行
- **用垂直间距把控件分组**（现在缺的就是这个）
- 依赖控件对齐到主控件的标签

```
[预设]  动画预设 [下拉 ▾]    颜色预设 [下拉 ▾]     ← 最显眼

总开关
  ☐ 启用拖尾光标（总开关）
  拖尾渲染模式  [弹簧拉伸（Neovide 原版效果）▾]
  ☐ 隐藏原生光标（覆盖层充当光标）
  ☐ 常驻刷新（永远按 8ms 调度）

淡出
  ☐ 辉光淡出（停止后柔和熄灭）
  淡出前保持时长   [====|====] 50 ms   [ 50 ]
  淡出时长         [====|====] 75 ms   [ 75 ]

颜色与辉光
  拖尾颜色   [■ #FFC0CB]      拖尾不透明度  [====] 1.00 [ 100 ]
  ☐ 启用辉光
  辉光颜色   [■ #FFC0CB]      辉光峰值不透明度 [====] 0.55 [ 55 ]
  辉光层数   [====|===] 8 层   [ 8 ]
  辉光外扩幅度 [====|===] 0.20  [ 20 ]

▸ 拖尾手感（可折叠）
  拖尾密度       [====|====] 1.00  [ 100 ]
  拖尾拉伸强度   [===|=====] 4.5×  后缘 110ms / 前缘 24ms  [ 45 ]

▸ 动画时序（可折叠，高级）
  跨行动画时长   [====|====] 0.10 s  [ 10 ]
  短动画时长     [====|====] 0.11 s  [ 11 ]
```

改进点：预设置顶 / 输入框吸附+精细 / 高级折叠 / 垂直间距分组 / 关掉刻度标签。
