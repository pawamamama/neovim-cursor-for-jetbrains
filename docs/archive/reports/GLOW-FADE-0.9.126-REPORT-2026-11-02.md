## 三、根因

### 3.1 「必须停下才暗」是 0.9.125 的代码选择

`CaretAnimator.tickSpring()` 当时写的是：

```java
float fade = glowFade(now);
if (glowStrength > 0f) {        // 只要拖尾还有一点偏移
    lastAnimatingNanos = now;   // 淡出计时起点被每帧重置
    fade = 1f;                  // 强制不淡出
}
```

同时 `GlowIntensity.glowForGroup()` 在「本组最近活动过」时直接返回保持值 1.0，不看当前偏移。实际时间线：

```
0 ~ 122ms     拖尾收拢，亮度钉在 1.0
122ms         光标视觉上停住
122 ~ 172ms   继续保持 1.0（保持 50ms）
172 ~ 247ms   才开始线性淡出（75ms）
```

### 3.2 为什么不能简单「按键就按时间淡出」

拖尾长度不固定：

| 场景 | 拖尾持续时间 |
|---|---|
| 单行打字 8px | 约 120ms |
| 基础跨行 32px | 约 155ms |
| 缎带跨行 0.28s | 约 430ms |

75ms 的时间淡出会在缎带还在展开时结束——0.9.118 实测缎带 **72% 的时间无光**。

### 3.3 为什么不能简单「亮度=偏移曲线」

`strengthFor()` 只在偏移 0.5 ~ 2.5px 之间从 0 升到 1。拖尾收拢到最后 2px 时曲线才开始掉，此时亮度已只剩约 1.5%；再乘 75ms 淡出，肉眼不可见（0.9.124）。

### 3.4 多光标拆组的隐藏缺陷（审查 H-1）

本次初版把「组亮度」写回组内每个 trail。若一个光标在相邻行组里移动、另一个静止，静止 trail 的 `GlowState.brightness` 也被写成 1；当移动光标跳走/被移除、组拆开后，静止 trail 会以这个 1 为起点单独淡出**一整个淡出时长**（最长 1 秒）。这违反 AC-5「静止组不因另一组移动而发光」，且旧探针没有覆盖。

## 四、方案

### 4.1 B 方案：目标曲线 + 限速下降

```
目标亮度 = strengthFor(当前偏移)          // 拖尾还在，目标就不会归零 → 跨行不中断
当前亮度上升：立即到目标                  // 按键立刻回满（AC-2）
当前亮度下降：每帧最多下降 dt / 淡出时长   // 淡出时长 = 下降速度上限
保持期：从「最后一次移动」起算            // 不是从拖尾收拢起算
```

效果：拖尾收拢的最后一段，曲线开始降，亮度跟着降；拖尾归零后以同一速度继续降。参数不再决定「何时开始」，而是决定「降多慢」。

### 4.2 逐 trail 状态 + 组内显示 max（H-1 修复）

- 每个 `SpringTrail` 只保存自己的 `brightness` 与 `lastMoveNanos`。
- 每个 trail 只按自己的偏移/移动时刻推进。
- 同组渲染时取组内最大亮度（相邻行看起来是一个整体）。
- **不再把组亮度写回成员**：拆组后静止 trail 的状态仍是 0。

### 4.3 没选的方案

| 方案 | 否决原因 |
|---|---|
| A 只调参数（保持 0.9.125） | 「停下后才暗」不变，预计不满足第 1 条硬要求 |
| C 只改感知曲线 `(1-t)^3` | 不能实现「跟着拖尾一起暗」；若作用到全程还会放大 10 键/秒呼吸 |
| D 按层数变暗 | 只有 9 个离散档，用户明确说算改手感 |
| 纯时间淡出 | 缎带中途熄灭（0.9.118 的 72% 无光） |
| 纯偏移曲线 | 淡出从 1.5% 开始，参数无效（0.9.124） |

### 4.4 逐帧对照（单行打字，D=8px，L=0.11s，hold=50ms）

| 时间 | 0.9.125 | B（fade=75） | B（fade=300） | B（fade=500） | 光晕面积（近似） |
|---|---|---|---|---|---|
| 0ms | 1.000 | 1.000 | 1.000 | 1.000 | 701 px² |
| 50ms | 1.000 | 1.000 | 1.000 | 1.000 | 648 px² |
| 100ms | 1.000 | 0.573 | 0.893 | 0.936 | 613 px² |
| 300ms | 0.000 | 0.000 | 0.227 | 0.536 | 599 px² |

跨行 D=32px、L=0.10s：0/50/100ms 两种模型都接近满亮；300ms 时 B（fade=300）仍有 0.360，0.9.125 已归零。缎带 0.28s：B 在 300ms 仍为 0.97，收尾跟着曲线下降。
